Why this is agentic, not ordinary YOLO

YOLO supplies detections. The agent chooses its next observation: it selects extra frames based on confidence and previous support, compares candidate motion with surrounding-road motion, and records every request and result.

What makes RoadGuard different

01

Global road-damage vision

YOLOv8n ONNX trained on 25,619 images across seven RDD2022 source sets. OpenCV 5 performs decoding, preprocessing, CPU DNN inference and class-aware suppression. Four road-damage classes.

OpenCV 5ONNXMulticountry training
02

Adaptive agentic reinspection

The agent tests additional frame offsets when confidence is low or temporal support is insufficient. Inspection requests and matching outcomes are recorded, not hidden.

Confidence-awareTool callsTemporal evidence
03

Motion-based artifact checks

Sparse Lucas–Kanade optical flow compares candidate-region motion with surrounding road motion. It raises a possible camera-fixed artifact signal rather than asserting a reflection is proven.

Optical flowHeuristic safety check
04

Auditable evidence trail

Every candidate includes source frame, box, model confidence, associated observations, reinspection tool results and unmodified/annotated images. Inspectors can challenge the AI's claim.

Explainable workflowTraceable evidence
05

Actual AWS-side inference

This public UI calls an API hosted on Amazon EC2. The host runs the same CPU OpenCV/ONNX inspection code; private S3 receives source video, evidence and trace; S3 events trigger Lambda to generate review summaries.

EC2 computeS3Lambda
06

Human-governed decisions

AI findings never become automatically verified road defects. A reviewer can confirm, reject or request further evidence; a timestamped decision history is stored in private S3.

Responsible engineering boundaries

RoadGuard does not infer GPS location, measure crack depth, calculate repair costs or claim infrastructure safety. Temporal groups are image-space associations, not verified distinct physical defects. A camera artifact can remain undetected.

Cloud video inference is on EC2, not inside the S3-triggered Lambda function. A hosted demo is not automatically a horizontally scalable production service.

Human review & audit trail

Inspectors review the model evidence and decide whether each candidate is accepted, rejected or needs further inspection. Decisions are stored in S3, not just in the browser.
